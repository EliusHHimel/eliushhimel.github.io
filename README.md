# Interactive 3D Portfolio Website

An immersive 3D portfolio website built with React, Three.js, and React Three Fiber.

## Features

- **Interactive 3D Graphics**: Fully animated 3D scenes powered by Three.js
- **Multiple Sections**: Navigate through Hero, About, Skills, Projects, and Contact sections
- **Responsive Design**: Works across different screen sizes
- **Modern Tech Stack**: Built with React 18 and React Three Fiber

## Tech Stack

- **React** - UI library
- **Three.js** - 3D graphics library
- **React Three Fiber** - React renderer for Three.js
- **Create React App** - Build tooling

## Sections

1. **Hero** - Animated torus knot with particle background
2. **About** - Pulsating sphere with orbiting satellites
3. **Skills** - Floating animated cubes showcasing technologies
4. **Projects** - 3D project cards with animated grid
5. **Contact** - Pulsing sphere with orbiting rings and starfield

## Available Scripts

### `npm start`

Runs the app in development mode.  
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.

### `npm run build`

Builds the app for production to the `build` folder.  
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.  
Your app is ready to be deployed!

### `npm run deploy`

Deploys the built app to GitHub Pages.

## Deployment

The site is configured to deploy to GitHub Pages. Simply run:

```bash
npm run build
npm run deploy
```
